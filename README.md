# earth1.co

The website of **Earth One Global Coalescent**: the philosophy and the argument behind [e1-4](https://e1-4.com).

> earth1.co argues; e1-4.com builds.
> *Global Citizenship For All.*

This repo currently holds the **build instructions for Devin**. The site itself will be built from them, one task at a time.

## How to run a Devin session

1. Tick off the "Before Task N" items in the founder checklist.
2. Copy the whole code block for the next task from `docs/devin/TASKS.md` into a new Devin session.
3. Answer Devin's "questions before starting".
4. Review the PR on the preview URL (on your phone, too). Merge it yourself if the task says "founder review".
5. Next task.
