# e1-4 build pack (for Devin)

Everything Devin needs to build **e1-4.com**, the flagship voice-only platform. It lives here until the e1-4 repo exists.

| File | For | What it is |
| --- | --- | --- |
| [`SETUP.md`](SETUP.md) | **Founder** | What you need: accounts, costs, the OAuth set-up steps, decisions |
| [`DEVIN.md`](DEVIN.md) | Devin | Master instructions: product spec, stack, milestones M0–M8, rules |
| [`TASKS.md`](TASKS.md) | Founder → Devin | Ready-to-paste tasks 1–4, plus a "plan the next milestone" prompt for everything after |
| [`CONTENT.md`](CONTENT.md) | Devin | Landing-page and legal copy, verbatim |

## Start the e1-4 repo

1. Create a new GitHub repo, e.g. `quantumleapsfusion-ops/e1-4`.
2. Copy into it:
   - `e1-4/DEVIN.md`, `e1-4/TASKS.md`, `e1-4/CONTENT.md`, `e1-4/SETUP.md` → repo root
   - `docs/BRAND.md` and `docs/DOMAINS.md` from this repo → `docs/`
   - your Ψ/π logo files → `public/brand/`
3. Add an `AGENTS.md` at the root: "Read DEVIN.md in full before any work."
4. Work through `SETUP.md` "Before Task 1", then paste Task 1 from `TASKS.md` into Devin.

(Or ask Claude to create the repo and do steps 2–3 for you.)
